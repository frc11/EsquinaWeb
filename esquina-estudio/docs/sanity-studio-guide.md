# Sanity Studio Guide

Studio URL after deploy: `https://your-domain.com/studio`

## Access

1. Go to `manage.sanity.io`.
2. Open the Esquina Estudio project.
3. Invite Virginia and Victoria from Members.
4. Assign the Editor role so they can add and edit content without changing schemas.

## Add A Project

1. Open Studio and choose Project.
2. Add the project title, slug, project number, category, services, year, and cover image.
3. Use project numbers like `01`, `02`, `03`.
4. Add content blocks in the order they should appear: text, single media, or dual media.
5. Preview the page, then publish.

## Add Fun Gallery Images

1. Open Fun Gallery Image.
2. Upload the image.
3. Add a short alt text.
4. Set an order number if a specific sequence is needed.
5. Publish.

## Notes

- Images should be high quality and compressed when possible.
- Use GIF/video only where movement is important.
- If a project should appear first, give it the lowest order number.
